            常见问题
          
          
        
          

        
          
          
          
            哪儿不对劲，先在这儿找找。找不到就把日志发给作者——
            一键打开日志文件夹的按钮在最下面。
          
          

          
          
            
          常见问题
          

            
          
              点了「开始游戏」没反应，或者一闪就退
              
          
                先看顶栏「日志」按钮里最后几行。最常见的原因是启动器提示
                "有 N 个游戏文件不在了"——那说明版本装得不全，到「下载」页对着这个版本
                点「重装」，缺的会自动补齐（已经下好的不会重下）。
              
          
            
          

            
          
              游戏报 "Java 版本不对" 或者闪一下就崩
              
          
                这个版本要的 Java 和本机找到的对不上。毛球会在启动前自动补下正确的 Java
                （几百 MB，第一次会慢一点）。要是还不行：到「下载」页对着这个版本点「重装」。
                版本设置里能看到"将会使用的 Java"。
              
          
            
          

            
          
              下载特别慢
              
          
                到「设置 → 启动选项」里把「下载源」换成国内镜像。默认是"自动"，网络不好时
                它自己也会切，但手动指定更快。
              
          
            
          

            
          
              怎么装 Mod / 资源包 / 光影包？
              
          
                到「下载」页搜名字，点一下就行——毛球会自动放进该放的文件夹。
                整合包直接把压缩包拖进窗口也能装（带密码的会问你要密码）。
                装完回启动页选那个版本，点「开始游戏」。
              
          
            
          

            
          
              和朋友联机连不上
              
          
                ① 两个人都要在「联机」页里：一个创建房间、另一个输码进来；
                ② 房主进游戏开好世界后，按 Esc 点「对局域网开放」；
                ③ 还进不去就用「直接连接」，填毛球显示的地址（形如 10.126.126.1:54321）;
                ④ 检查两边的杀毒软件/防火墙有没有拦"虚拟网卡"。
              
          
            
          

            
          
              我的存档在哪？会丢吗？
              
          
                存档在游戏目录的 saves 文件夹里（开了版本隔离的话在
                versions\版本名\saves 里）。毛球不会动它——删除版本、清理垃圾
                都不碰存档。怕丢就到「设置 → 备份」一键备份一份。
              
          
            
          

            
          
              版本装多了想清一清
              
          
                两种：① 「设置 → 清理」清游戏日志和崩溃报告；② 到「启动页 → 版本设置 →
                删除这个版本」整个删掉（**会二次确认**，且只删这个版本自己的文件）。
              
          
            
          

            
          
              出问题了，怎么把日志发给别人看？
              
          
                点下面的「打开日志文件夹」，里面最新的那个 launch-*.log 就是最近一次启动的
                完整记录；游戏自己的日志在同目录的「游戏日志」里。把文件整个发出去就行。
              
          
            
          
          
          

          
          
          
            
          AI 助手怎么用
          
            
          
              左边那颗四角星就是它。顶上两个开关，花不花钱你自己说了算——
              能用本地规则库（一分钱不花），也能用你自己的 AI（免费，但要你先去拿个钥匙）。
            
          

            
          
              ① 先用「本地规则库」——不联网、不花钱、立刻有答案
              
          
                不用注册也不用填任何东西，点开就能问。它认得常见的毛病：
                Java 版本不对、内存给少了、Mod 缺前置或者打架、显卡、端口被占、下载失败……
                每条都说清「是什么毛病 → 为什么 → 一二三四步怎么办」。
                它答不上来的会老实承认，那时候再切到「我的 AI」。
              
          
            
          

            
          
              ② 「我的 AI」怎么开：去拿一个免费的 Key（一次就够了）
              
          
                点「AI 助手」页右上角的「我的 AI」——没填过 Key 的话，毛球会自动把你送到设置页。
                然后三步：
              
          
              
          
                1. 点「打开智谱开放平台」去注册（手机号就行，不用绑卡、不用充钱）；
          
                2. 在那边建一个 API Key，把那一长串复制下来；
          
                3. 回毛球粘进「API Key」框 → 点「存下来」→ 点「测试连接」。
                显示"通了"就说明能用了。
              
          
              
          
                模型名字已经帮你填好了（glm-4-flash-250414，免费的、很快）。
                记住一件事：Key 不绑模型——想换个模型（更新的、或者别家的 DeepSeek / 豆包 / Kimi）
                只改那个名字就行，不用重新申请。
              
          
            
          

            
          
              ③ 游戏崩了，怎么让它帮我看看
              
          
                左下角点「日志」——最上面就是毛球自己认出来的毛病，
                右上角有个「问问 AI」按钮：点它会跳到 AI 页，
                并且自动挑好「最近一次出问题的那份日志」
                （不是最新那份——你崩了之后多半又开了好几次游戏，最新那份往往是正常的）。
              
          
              
          
                发出去之前会弹一层「给你看一眼」：里面就是真正要发走的内容，
                能改能删，你点确认才发。里面已经自动把你的用户名、账号名、房间码抹掉了，
                但 Mod 名字和报错内容会留着——那是它判断毛病的依据。
              
          
            
          

            
          
              ④ 到底花不花钱？我的东西会被传出去吗？
              
          
                · 本地规则库：一分钱不花，也不联网；
          
                · 我的 AI：花的是你自己账号的额度——默认那个模型是免费的，正常用不掏钱；
                你要自己换成付费模型才需要充值。一次最多发 8000 个字，替你把着钱；
          
                · 日志是你点确认才发，发之前能看到全文；
          
                · Key 加密存在你自己电脑上；聊天记录只在内存里，关掉毛球就清空。
              
          
            
          

            
          
              ⑤ 报错了看不懂、或者它一直不动，怎么办
              
          
                · Key 不对 → 会说"看看是不是少复制了一位"；
          
                · 模型挤不上（免费模型赶上人多）→ 会把平台的原话给你看，并告诉你换哪个模型名；
          
                · 问太快 → 免费额度有速度限制，等一会儿再问；
          
                · "正在想…"半天不动 → 那行字会一直报秒数（"已经等了 20 秒"），
                90 秒还没回就会明确告诉你，不会让你干等着。
              
          
            
          

            
          
              ⑥ 它说的能全信吗？
              
          
                不能全信。AI 会一本正经地胡说，动手之前先想想合不合理，
                尤其别照着它编出来的路径去翻文件。它是帮你缩小范围的，不是替你拍板的。
                每条回答下面也都写着这句话。
