          版本隔离

          开着（推荐）：每个版本的存档、Mod 各放各的文件夹，互不干扰。
          关着：所有版本共用游戏目录里的那一套，换个版本玩会看到同一批存档。
          这里是全局默认——想给某一个版本单独开或关，去那个版本的「版本设置」里改。

          常见问题
          哪儿不对劲，先在这儿找找。找不到就把日志发给作者—— 一键打开日志文件夹的按钮在最下面。

          常见问题

          点了「开始游戏」没反应，或者一闪就退

          先看顶栏「日志」按钮里最后几行。最常见的原因是启动器提示 "有 N 个游戏文件不在了"——那说明版本装得不全，到「下载」页对着这个版本 点「重装」，缺的会自动补齐（已经下好的不会重下）。

          游戏报 "Java 版本不对" 或者闪一下就崩

          这个版本要的 Java 和本机找到的对不上。毛球会在启动前自动补下正确的 Java （几百 MB，第一次会慢一点）。要是还不行：到「下载」页对着这个版本点「重装」。 版本设置里能看到"将会使用的 Java"。

          下载特别慢

          到「设置 → 启动选项」里把「下载源」换成国内镜像。默认是"自动"，网络不好时 它自己也会切，但手动指定更快。

          怎么装 Mod / 资源包 / 光影包？

          到「下载」页搜名字，点一下就行——毛球会自动放进该放的文件夹。 整合包直接把压缩包拖进窗口也能装（带密码的会问你要密码）。 装完回启动页选那个版本，点「开始游戏」。

          和朋友联机连不上

          ① 两个人都要在「联机」页里：一个创建房间、另一个输码进来； ② 房主进游戏开好世界后，按 Esc 点「对局域网开放」； ③ 还进不去就用「直接连接」，填毛球显示的地址（形如 10.126.126.1:54321）; ④ 检查两边的杀毒软件/防火墙有没有拦"虚拟网卡"。

          我的存档在哪？会丢吗？

          存档在游戏目录的 saves 文件夹里（开了版本隔离的话在 versions\版本名\saves 里）。毛球不会动它——删除版本、清理垃圾 都不碰存档。怕丢就到「设置 → 备份」一键备份一份。

          版本装多了想清一清

          两种：① 「设置 → 清理」清游戏日志和崩溃报告；② 到「启动页 → 版本设置 → 删除这个版本」整个删掉（**会二次确认**，且只删这个版本自己的文件）。

          出问题了，怎么把日志发给别人看？

          点下面的「打开日志文件夹」，里面最新的那个 launch-*.log 就是最近一次启动的 完整记录；游戏自己的日志在同目录的「游戏日志」里。把文件整个发出去就行。
