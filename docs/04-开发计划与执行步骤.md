**为什么把"Modrinth"排到"装加载器"前面**（2026-10-07 调整了原预告的顺序）：

原来的预告是"先装加载器、再接 Modrinth"。真开工时改了，理由：
**资源包和光影包不需要任何 Mod 加载器就能用**——M9 做完，用户当天就能
下载并换上喜欢的资源包/光影；而只装加载器是看不到任何效果的。
另外"下载文件并放到该放的地方"是所有后续功能（Mod、整合包）共用的地基，
先把它做扎实，后面两个里程碑都能直接站在上面。

**CurseForge 的限制（做到 M9/M11 时要提前告诉用户）**：

7. ✅ **缓存**：先给缓存（快、断网也能看），有缓存时后台再悄悄更新

**踩到的坑：镜像不是简单换域名**

不同资源的映射规则不一样，搞错就是 404 或下载失败：

| 官方域名 | 镜像规则 |
|---|---|
| `piston-meta.mojang.com` | 同路径（会 302 跳转，跟着走） |
| `piston-data.mojang.com` | 同路径 |
| `libraries.minecraft.net` | **要加 `/maven` 前缀** |
| `resources.download.minecraft.net` | **要加 `/assets` 前缀** |

后两条特别容易搞错。**动代码前先用真实地址逐个验证过**，
没靠猜——猜错的话要等到 M4 真下载时才会暴露，那时候排查成本高得多。

**另一个坑：Node 的 https 不会自动跟随跳转**

`https.get` 拿到 302 会把跳转响应直接给你，**不跟**。
而 Mojang 和国内镜像都会跳转（镜像甚至跳到它自己的对象存储），
不处理的话拿到的是空响应，还会以为"下载成功了"。所以 http.js 里自己实现了跟随。

**产出**：打开「下载」页能看到 918 个版本，能筛选能搜，断网也能看上次的列表。

## M3 · 下载引擎

**目标**：能可靠地把一堆文件下下来。

**步骤**
1. `src/main/downloader.js`：并发下载队列（默认 8 个并发）
2. 先下到 `.part` 临时文件，**校验 SHA1 通过后才改名**成正式文件
3. 失败自动重试（最多 3 次，间隔递增）
4. 已存在且校验通过的文件**直接跳过**（共享文件不用重下）
5. 实时上报：已完成数 / 总数、速度、剩余时间
6. 支持暂停 / 取消
7. 镜像切换：连续几个文件都慢于阈值 → 换镜像

**产出**：能下单个文件、显示进度和速度、断网重试、校验不通过自动重下。

**注意**：这一步不碰游戏，只把"下载"这件事本身做扎实。

## M4 · 安装一个版本

**目标**：点一个版本 → 真的把它装到硬盘上。

**步骤**
1. 下载版本 JSON，解析出需要哪些文件
2. **先摸清 Java 运行时怎么下载**（这是本里程碑最大的未知数）
3. 装客户端 jar
4. 装 libraries（几十个 jar）
5. 解压 natives 到版本目录
6. 装 assets（几千个小文件，最耗时）
7. 全部完成后，把版本写进"已装版本"列表
8. 界面：下载页每个版本有「安装」按钮；显示整体进度

**产出**：选一个版本点安装 → 进度条走完 → 版本出现在列表里。

**注意**：Java 那一步如果接口走不通，**立刻降级**为"让用户手动指定 Java 路径"，
不要卡在这里。

## M8 之后的候选（2026-10-07 对照 PCL 逐页看完整理）

用户要求"浏览一遍 PCL 页面"后整理的。**先记着，不急着做**——
按性价比排了优先级，等 M8 打包完、用户真用一阵子再挑。

| 优先 | 候选 | 是什么 | 为什么值得做 |
|---|---|---|---|
| ⭐⭐⭐ | 启动按钮上写版本名 | PCL 那个大按钮里直接写着 ATM10SKY | 一眼知道启动的是哪个版本，改动很小 |
| ⭐⭐⭐ | 版本设置里写明"将会使用的 Java" | PCL 会写"将会使用：Java 21…java-runtime-delta\bin\" | 出问题时用户能说清楚用的是哪个 Java |
| ⭐⭐⭐ | 版本设置/卡片显示版本类型 | PCL 写"正式版 1.21.1" | 我们只显示版本号，不知道是正式版还是快照 |
| ⭐⭐ | 「清理游戏垃圾」 | PCL 百宝箱里的一键清理（日志、崩溃报告） | 实际有用，不用用户自己去翻文件夹 |
| ⭐⭐ | 「帮助」页 | PCL 有一整页指南 + 搜索 | 可做简化版：常见问题 + 一键打开日志 |
| ⭐ | 最大线程数 / 速度限制 | PCL 设置里的两个滑块 | 网络不好时用户能自己调 |
| ⭐ | 图标 / 分类 / 收藏 | PCL 版本设置的"个性化" | 多版本以后有用 |
| — | 个性化（背景图/背景音乐/标题栏样式） | PCL 设置里的"个性化"页 | 好看，但属于锦上添花 |
| — | 功能隐藏 | PCL 可以把不要的页面藏起来 | 我们页面本来就少，暂时用不上 |

**对照时发现的、我们做得比 PCL 好的地方**（记下来，别丢了）：

1. **原版版本列表可用**：同一网络下 PCL 的原版游戏页直接报"网络环境不佳"，
   我们的会自动换国内镜像，照样列出 918 个版本
2. 版本列表就在启动页左边，不用点开弹窗再选
3. 不做匿名数据收集（PCL 设置里有这个开关）
4. 有**一键备份**（PCL 只有"导出整合包"，没有给普通用户用的备份）
5. 装到一半取消时**会问保留还是删掉**（PCL 没这个选择）

**也已经确认过：PCL 的"内存分配：跟随全局设置/自动配置/自定义"和我们
给每个版本单独设的做法一致**——说明这条路是对的。
