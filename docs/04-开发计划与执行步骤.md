### 规矩（来自官方对接文档 §0，硬性）

- 唯一合法的变换是**语言转换**：逐语句、逐常量、逐时序地把 VoxLink 的 Java 翻成 JS
- **不许自创**：源码里没有的常量、字段、分支、重试策略，一个都不许出现
- **不许简化**：不合并步骤、不砍守卫、不改重试预算
- 文档 / 指令 / 源码三者打架时——**以源码为准**，并把疑问反馈给仓库方，不自行裁决
- 用户可见文案走毛球自己的写法，不硬编码在逻辑里

### 已知依赖与风险（做不到的事要第一时间说）

- **依赖作者的免费服务器 `p2p.wuhui.icu`**（2026-10-12 实测活着，回 200）。它随时可能关，

**踩到的坑：镜像不是简单换域名**

不同资源的映射规则不一样，搞错就是 404 或下载失败：

| 官方域名 | 镜像规则 |
|---|---|
| `piston-meta.mojang.com` | 同路径（会 302 跳转，跟着走） |
| `piston-data.mojang.com` | 同路径 |
| `libraries.minecraft.net` | **要加 `/maven` 前缀** |
| `resources.download.minecraft.net` | **要加 `/assets` 前缀** |

后两条特别容易搞错。**动代码前先用真实地址逐个验证过**，
没靠猜——猜错的话要等到 M4 真下载时才会暴露，那时候排查成本高得多。

**另一个坑：Node 的 https 不会自动跟随跳转**

`https.get` 拿到 302 会把跳转响应直接给你，**不跟**。
而 Mojang 和国内镜像都会跳转（镜像甚至跳到它自己的对象存储），
不处理的话拿到的是空响应，还会以为"下载成功了"。所以 http.js 里自己实现了跟随。

**产出**：打开「下载」页能看到 918 个版本，能筛选能搜，断网也能看上次的列表。
