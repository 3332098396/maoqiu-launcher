---

## 一句话说明

**毛球**是一个运行在 Windows 上的 Minecraft Java 版启动器，
能下载游戏、登录账号、启动游戏、管理版本，目标是做到类似 PCL 的体验，
但要更简单、更"说人话"。

> **名字的由来**：这个软件原来叫「MC启动器」（项目文件夹也还是这个名字）。
> 2026-10-07 用户拍板改叫「**毛球**」。

## 要解决的问题

官方的 Minecraft 启动器功能有限：不能方便地管理多个版本、装不了 Mod 加载器、
下载慢、界面复杂。这个软件把这些事收拢到一个**简洁、直观**的界面里。

**正版登录的那道门（2026-10-08 查证 + 一次实测）**

微软那边注册应用是免费的、自己就能办；卡点在 **Mojang 的人工审核**：
**没进 Mojang 许可名单的 client_id**，换游戏令牌那一步会直接回
`403 Invalid app registration`（"这个应用没登记过"）。表单在 `aka.ms/mce-reviewappid`，
有人填了等 3~4 周批下来了，也有人去问微软得到的答复前后不一致（被踢到 ID@Xbox，
那边又说"不归我管"）——**批不批、多久，都不归我们控制**。

所以做法是：**毛球不内置任何客户端 ID，ID 由使用者自己填**（HMCL 就是这么设计的，
它连默认值都不给）。将来申请批下来，把 ID 一填就通，不用改代码。

> **2026-10-08 实测补充——把话说明白，别让人误会**
>
> 上面那句"会被挡"，**只针对"自己新注册的 ID"**。**已经进了名单的 ID 不会被挡**——
> 最典型的就是**官方启动器自己那个应用 ID**。用户自己改装了一份装好的程序、
> 用那个 ID 走老 Live 的授权码流程（`login.live.com`），**实测一路通到底**。
>
> 所以准确的说法是：**"这条路技术上通，用的是 Mojang 自己的应用身份"**，
> 而不是"这条路走不通"。之前写成前者会更准。
>
> **但项目仍然不做它**——源码里既不内置、也不借用别人的 ID。理由不是"它跑不起来"，
> 而是：那是**别人的应用身份**，而且那个 ID 什么时候被限流或停掉**不归我们管**，
> 用户会毫无预兆地登不上、还查不出原因。**用户在自己机器上怎么改装是用户的事；
> 毛球的源码保持干净。**

### ⚠️ CurseForge 整合包的限制（必须记下来，避免以后困惑）

CurseForge 的整合包里只写"第 12345 号 Mod 的第 67890 号文件"，**不写下载地址**。
启动器得自己拼地址去下。

**以前拼地址不需要密钥，但 CurseForge 官方后来给文件下载加了强制认证**——
没有密钥的请求直接返回 `401 未授权`，而且明确要求密钥**不能放在公开分发的软件里**。

**密码解决不了这个问题**——密码只能解开压缩包，解不开"文件要从哪下"。

**唯一的合规绕法**：用户自己去 CurseForge 申请一个密钥，填进软件设置里。
只给自己用是合规的。代价是要填表申请、等审核。

> **这条对用户是有实际影响的**：他自己在用的 ATM10SKY 就是 CurseForge 的整合包。
> 所以实现到这一步时要提前告诉他，别让他等一个做不出来的功能。

### 关于"带密码的压缩包"的技术现实（写给开发时看）

- **Node 自带的模块能解压、不能解密**。加密压缩包要自己实现解密算法：
  - 老式的 ZipCrypto（弱加密）：约 40 行
  - 现代工具常用的 AES 加密：约 100 行（Node 的 crypto 模块能做，需要 AES + PBKDF2 + HMAC）
- 不同压缩软件（WinRAR / 7-Zip / Windows 自带）用的加密方式可能不同，**都要能识别**
- 密码错了要明确提示"密码不对"，而不是报一堆看不懂的错
- **这块容易在细节上翻车**，做的时候要多造几个不同工具加密的样本测试

### 「房间码」背后是怎么运作的（写给以后看的人）

用户和好友的电脑各自在运营商的大内网里，**互相看不见**。所以必须有个"中间人"：

1. **牵线**：双方用同一个房间码进来，中间人告诉彼此对方在哪 →
   两台电脑**尝试直接连**（P2P 打洞，最快）
2. **兜底**：直连不通时（很多网络环境不允许）由中间人**转发数据**（走中继，慢一些但能玩）

房间码本质上是 **EasyTier 的网络名称 + 密码**编码成的短字符串——
不神秘，就是"让双方能用同一个暗号进同一个虚拟网络"。

## 三、明确"不做"的事（范围边界）

这些是**有意不做**的，不是遗漏。如果以后要做，先加进这份文档再动手。

| 不做的功能 | 原因 |
|---|---|
| **CurseForge 作为下载源** | 要 Overwolf 人工审核，且条款**明令禁止**把 API 密钥内嵌进启动器。合规做法是自己架服务器转发，个人项目不现实 |
| **MC百科作为下载源** | 查证过：**没有官方下载接口**。非官方爬取有合规风险，而且 MC百科自己的下载页也是跳转到别处 |
| 「星叶云联」 | **2026-10-07 用户提供了网站：`www.xyebbs.com`（XyeBBS，星叶）**。查证结果：那是一个**我的世界中文资源论坛**（整合包 6 千个、资源 2.8 万个，还有模组/插件/地图/光影/汉化），**不提供联机服务**（站内没有联机组网相关内容）。它也**没有公开接口**，而且下载要登录/积分——和 MC百科同一类情况，**不做自动对接**。<br>**但它有个用处**：用户可以在那上面下整合包，然后**拖进毛球自动安装**（R6.4~R6.6，M11 做）——不需要对接也能用 |
| 读用户现有的 PCL 游戏目录 | 用户选择"各玩各的"，避免互相干扰 |
| 正版登录（第一期） | 卡在 Mojang 对第三方启动器 client_id 的审批，不是代码问题 |
| 内置服务器 / 开服功能 | 范围外 |
| Mac / Linux 版 | 只做 Windows |
| 自动更新启动器 | 第一版不做，用户手动下载新安装包 |
