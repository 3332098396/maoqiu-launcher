## 一、现在怎么运行（开发阶段）

在 `D:\MC启动器` 目录下：

```
npm start
```

## 二、安装与使用（M8 之后补全）

下面是**预计的**使用流程，等做到那一步再逐条核实。

### 安装

1. 双击 `MC启动器-安装程序-1.0.0.exe`
2. **可能**会跳出蓝色警告「Windows 已保护你的电脑」——这是个人开发、没买数字签名的软件都会遇到的，**不是中毒**
   - 点「**更多信息**」→ 点「**仍要运行**」
3. 装完自动启动，桌面出现**草方块图标**

### 第一次使用

1. **填个名字**（离线账号，随便填）
2. 点「**下载**」→ 选一个版本 → 点「**安装**」
   - 第一次要下 500 MB~1 GB，**耐心等**，界面上有进度和速度
3. 装完回到「**启动**」页 → 点「**开始游戏**」
4. 第一次启动要等一会儿（游戏在生成配置）

### 想装 Mod？（第二期才有）

现在还没做。等做完了这里会写清楚怎么装。

## 三、常见问题（会随开发补全）

### 下载很慢 / 卡住不动

启动器会自动在官方源和国内镜像之间切换。如果一直很慢：
检查设置里的下载源，或换个时间再试。

### 游戏启动失败

启动器会把游戏的报错翻译成中文，并给出常见原因。
如果看不懂，把提示截图发我。

### 杀毒软件报毒

个人开发、没有数字签名的软件经常被误报。
这个启动器**只从 Mojang 官方和知名镜像站下载文件**，代码全部在本项目文件夹里，可以自己查。

### 我的存档会被删吗

**不会。** 启动器只做两件会动文件的事：
① 往游戏目录里下载新版本；② 用户主动删除某个版本（有二次确认）。
卸载启动器**不会**删你的游戏和存档。

### 能和 PCL 共用游戏目录吗

**默认是各用各的**（本启动器用 `%APPDATA%\.minecraft`，
PCL 2 用的是它自己文件夹里的 `.minecraft`）。

如果你想共用，在设置里把游戏目录改成 PCL 的那个目录即可。
但**共用有风险**：两个启动器同时操作同一个目录可能冲突。
建议还是各用各的。
