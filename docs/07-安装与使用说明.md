# 07 · 安装与使用说明

> 这份文档给**使用软件的人**看，不需要任何技术背景。
> 里面写的每一步都在真机上实测过（M8 验收，2026-10-07）。

---

## 一、安装

1. 双击 **`毛球-安装程序-<版本号>.exe`**（**当前是 0.3.0**；文件名里那串数字就是版本）
2. 可能会跳出蓝色警告「Windows 已保护你的电脑」——这是**个人开发、没买数字签名**的
   软件都会遇到的，**不是中毒**
   - 点「**更多信息**」→ 点「**仍要运行**」
3. 安装向导有三步：
   - **给谁装**：选「仅为我安装」（默认，**不需要管理员权限**）
   - **装在哪**：默认装在 `C:\Users\<你的用户名>\AppData\Local\Programs\mc-launcher\`，
     **想换地方就点「浏览」自己选**（页面会显示需要多少空间、盘里还剩多少）
   - 点「安装」→ 装完自动打开软件
4. 桌面上和开始菜单里都会**自动出现「毛球」图标**（草方块）

## 二、第一次使用

1. **填个游戏名字**（离线账号，随便填，3~16 个字母数字）
   —— 游戏里显示的就是这个名字，联机时别人也认它
2. 点「**下载**」→ 选一个版本 → 点「**安装**」
   - 第一次要下 500 MB~1 GB，界面上有进度、速度、剩余时间，**耐心等**
   - 中途不想装了可以点「取消安装」，会问你已下好的要不要留着
3. 装完回到「**启动**」页 → 点「**开始游戏**」
4. 第一次启动要等十几秒（游戏在做首次初始化），之后会快一些

## 三、平时会用到的几个地方

| 想做什么 | 去哪 |
|---|---|
| 换版本、改名字、写备注 | 启动页左下角「版本设置」 |
| 打开存档 / Mod / 截图文件夹 | 「版本设置」里的四个按钮 |
| 调内存、窗口大小、版本隔离 | 顶栏「设置」 |
| 备份存档和设置 | 设置页 →「备份」（勾选要备份的 → 开始备份） |
| 看游戏日志（出错时） | 顶栏右上角「📄 日志」 |
| 删掉某个版本 | 「版本设置」→ 删除这个版本（会二次确认） |

## 四、常见问题

### 下载很慢 / 卡住不动

启动器会自动在**官方源和国内镜像**之间切换，不用自己设置。
如果一直很慢，换个时间再试；或者到「下载」页点一下「刷新」。

### 游戏启动失败

启动器会把游戏的报错**翻译成中文**并给出常见的几个原因。
如果还是看不懂：点顶栏「📄 日志」→「打开日志文件夹」，把日志发我。

### 杀毒软件报毒

个人开发、没有数字签名的软件经常被误报。
这个启动器**只从 Mojang 官方和知名镜像站（BMCLAPI）下载文件**，
所有代码都在项目文件夹里，可以自己查。

### 卸载软件会不会把我的存档删了

**不会。** 实测过：卸载只删程序本身（连同桌面和开始菜单的图标），
`%APPDATA%\毛球\` 里的设置和备份、`.minecraft` 里的游戏和存档**都原样保留**。

卸载方法：Windows「设置 → 应用 → 毛球 → 卸载」，或者直接运行安装目录里的
`Uninstall 毛球.exe`。

### 能和 PCL 共用游戏目录吗

**默认是各用各的**（毛球用 `%APPDATA%\.minecraft`，
PCL 2 用的是它自己文件夹里的 `.minecraft`）。

将来可以在设置里改游戏目录去共用，但**共用有风险**：
两个启动器同时操作同一个目录可能冲突。建议各用各的。

### 在输入框打字时弹出的那个"词建议"框

那是 **Windows 系统自带的"文本建议"**，不是软件的弹窗
（打英文会冒出 Test/Tested/Testify 这种词典补全）。
嫌烦的话：Windows「设置 → 设备 → 输入 → 当我键入时显示文本建议」关掉。

## 五、给开发者的补充（怎么自己跑 / 重新打包）

开发时不想装，直接在 `D:\MC启动器` 下：

```
npm start              开发模式运行
```

也可以双击项目根目录的 **`启动毛球.bat`**。

重新打包：

```
npm run icons    重新生成图标（草方块）
npm run dist     打包成安装包
```

生成的安装程序在 `release\` 里。打包前记得 `npm start` 跑一遍确认没问题。
