# 06 · 数据与隐私说明

> **这份文档是干什么的**
> 它回答三个问题：**什么东西存在哪？它会连哪些网站？怎么删干净？**

---

## 一、数据存在哪

分成**两个完全独立的地方**：

### 1. 启动器自己的配置

```
C:\Users\<你的用户名>\AppData\Roaming\毛球\
├── config.json        账号、内存设置、窗口大小、游戏目录等
├── cache\             版本清单缓存（删了会自动重新下）
├── logs\              每次启动游戏的完整输出（排查问题用，可以随时删）
└── backups\           一键备份生成的东西
```

> **2026-10-07 改过名**：软件原来叫「MC启动器」，数据目录也在这个名字下。
> 改名后程序会**自动把旧目录整个搬过来**（`MC启动器` → `毛球`），
> 账号、设置、备份都不会丢。

### 2. 游戏文件

```
C:\Users\<你的用户名>\AppData\.minecraft\        ← 默认位置，可以在设置里改
├── versions\           每个版本的 JSON、jar、natives
├── libraries\          共享的库文件（所有版本共用）
├── assets\             共享的音效、语言、贴图（所有版本共用）
├── saves\              存档（开启版本隔离时，存档在各版本目录里）
├── mods\               Mod
├── resourcepacks\      资源包
├── shaderpacks\        光影包
└── screenshots\        截图
```

**为什么游戏目录要用英文路径**：老版本的 Java 和部分 Mod 对中文路径处理不好，
容易报莫名其妙的错。所以默认放 `%APPDATA%\.minecraft`（纯英文），
只有启动器自己的配置目录用了中文名。

### 怎么找到它们

设置页里会有「打开游戏目录」和「打开配置目录」两个按钮。

## 二、它会连哪些网站

**启动器必须联网**（要下游戏），但**只连这几个固定的地方**：

| 域名 | 干什么用 | 谁提供 |
|---|---|---|
| `piston-meta.mojang.com` | 版本清单、版本 JSON | Mojang 官方 |
| `piston-data.mojang.com` | 客户端 jar、Java 运行时 | Mojang 官方 |
| `libraries.minecraft.net` | 库文件 | Mojang 官方 |
| `resources.download.minecraft.net` | 音效、语言、贴图 | Mojang 官方 |
| `bmclapi2.bangbang93.com` | **国内镜像**，官方源太慢时替换上面几个 | 社区志愿维护 |
| `api.modrinth.com` | 搜 Mod、资源包、光影、数据包（M9 起） | Modrinth 官方 |
| `cdn.modrinth.com` | 上面搜到的文件从这里下载（M9 起） | Modrinth 官方 |

**说明**：Modrinth 那两条只有在你**主动去「下载」页搜社区资源**时才会连——
不搜不连。搜索请求会把你输入的关键词发给 Modrinth（这是搜索功能本身要求的）。

### 隐私方面的实话

- **不收集任何使用数据**，没有统计、没有埋点
- **不上传你的任何文件**，只有"下载"，没有"上传"
- **不需要注册任何账号**

### 但有几件事你要知道

⚠️ **这些下载请求会暴露你的 IP** 给上面那些服务器——这是任何联网软件都免不了的。
镜像站（BMCLAPI）是社区志愿维护的，它能看到你下载了什么版本。

⚠️ **换下载源时要注意**：如果你在设置里填了**自定义下载源**，
那个源的所有者能看到你的请求。不要用来路不明的源。

⚠️ **第二期的联机功能**会把你的游戏数据通过 EasyTier 的节点转发给一起玩的人。
中继节点是社区贡献的，**理论上节点运营者能看到流量内容**（虽然不一定是明文）。
如果你介意，联机时可以设置"仅直连、不中继"（但那样可能连不上）。

⚠️ **正版登录（以后做的话）**会涉及微软账号的授权令牌。
令牌只会存在你自己电脑上，**绝不会上传到任何第三方**。

## 三、怎么备份

想换电脑、重装系统前：

1. **游戏**：整个 `.minecraft` 文件夹复制走（可能几十 GB，看你装了多少）
2. **配置**：整个 `%APPDATA%\MC启动器\` 文件夹复制走（很小）

新电脑上放回同样位置就行。

**注意**：复制前先把启动器和游戏都**关掉**，否则文件可能正在写入。

## 四、怎么彻底删除

### 只删启动器，保留游戏
到「设置 → 应用」里卸载"MC启动器"。
**游戏文件不会被删**（这是故意的——那是你几百小时的存档）。

### 删掉某个游戏版本
在启动器的版本列表里删（有二次确认）。

### 彻底删干净
1. 卸载"MC启动器"
2. 删掉 `%APPDATA%\MC启动器\`（这是启动器的配置）
3. 删掉 `%APPDATA%\.minecraft\`（**这是游戏和存档，想清楚再删**）

⚠️ **第 3 步会连同你的存档、Mod、截图一起删掉，且不可恢复。**
删之前请务必确认里面没有你还想留的东西。

## 五、会占多少空间

| 内容 | 大小 |
|---|---|
| 启动器本身 | ~250 MB（装完之后） |
| 一个原版版本 | 客户端 ~20 MB + 库 ~150 MB |
| **assets（共享，只下一次）** | **~300~800 MB** |
| Java 运行时（每个大版本一份） | ~50 MB |
| 装第二个版本时新增 | 通常只有 ~30 MB（共享文件都跳过了） |

所以：**第一次装大约 500 MB~1 GB，之后每加一个版本只多几十 MB。**

## 六、给开发者的补充说明

| 事项 | 规定 |
|---|---|
| 配置写入必须**先写临时文件再改名** | 断电时不会把配置写坏 |
| **绝不允许**删除用户游戏目录之外的文件 | 启动器只该管自己那摊事 |
| 删除版本 / 存档必须**二次确认**，且说明删的是什么 | 那是别人几百小时的成果 |
| 下载的文件**必须校验哈希** | 下坏了、被中间人改了，要能发现 |
| 不许引入任何统计 / 上报代码 | 隐私是这个软件的卖点 |
| 新增的联网域名必须**登记到本文档的表格里** | 让用户随时能查"它到底连了哪" |
| 开发和用户环境的数据**必须隔离** | 「历史粘贴板」项目为此踩过大坑 |
