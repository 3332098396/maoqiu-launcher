# 09 · 正版登录：申请步骤（用户操作手册）

> **这份是给用户看的**，一步一步照着点就行，不用懂代码。
> 全程免费，大概十分钟。做完把那个 ID 填进毛球的设置里。

---

## 先说清楚为什么非得你自己注册

毛球**不会内置任何应用 ID**（HMCL 也是这样，它连默认值都不给）。原因：

- 微软的应用条款要求**每个启动器用自己注册的 ID**，不许借别人的
- 更要紧的是**对你不安全**：ID 是别人的，人家哪天改了或者停了，
  你会**毫无预兆地登不上**，还查不出原因（因为不归你管）

而且就算注册完了，**还有一道门**（Mojang 的人工审核），这一步在下面第二部分。

---

## 第一部分：注册微软应用（约 10 分钟）

### 1. 打开申请页面

浏览器进 **https://portal.azure.com**

用你**玩 Minecraft 那个微软账号**登录（就是有正版的那个）。

> 页面可能是英文的。找不到就用页面顶上的搜索框搜 `应用注册`（或 `App registrations`）。

> ⚠️ **如果登进去报错**："所选的用户帐户在租户 'Microsoft Services' 中不存在…
> 需要先将该帐户添加为该租户的外部用户"——**这不是你操作错了**。
> 个人微软账号有时会被默认塞进微软内部那个"Microsoft Services"租户，
> 而那是个你管不了的地方。**别按提示去"把自己加进那个租户"，那是死路。**
>
> 按顺序试：
> 1. **先退出所有微软账号**（打开 outlook.com → 头像 → 退出登录），
>    然后**开一个无痕窗口**，手打 `portal.azure.com` 重新登录。
>    很多时候只是浏览器里混着好几个账号、或者上次选的目录记错了
> 2. 还不行 → 去 **https://azure.microsoft.com/free/** 免费注册一个 Azure 账号，
>    这一步会**顺手给你生成一个属于你自己的目录**（你自动是它的管理员），
>    之后再回 `portal.azure.com` 右上角头像那里「切换目录」
>    （⚠️ 这一步微软**可能要绑信用卡**做身份验证，不扣钱但会要卡）
> 3. 有**公司/学校的微软账号**的话最省事——那种账号天生就有目录。
>    **注册应用用哪个账号都行，不需要和你有 MC 的那个是同一个**

### 2. 新建一个应用

左边菜单 →「**应用注册**」→ 上面点「**+ 新注册**」

| 这一项 | 填什么 |
|---|---|
| 名称 | 见下面那条**命名禁区**。安全的选择：`Maoqiu Launcher` 或 `毛球启动器` |
| 受支持的帐户类型 | 选「**仅个人 Microsoft 帐户**」（Personal Microsoft accounts only）<br>（选「任何组织目录 + 个人帐户」也行，毛球两种都认——见下面那条注意事项） |
| 重定向 URI | 平台下拉框选「**移动和桌面应用程序**」，右边那栏填/勾：`https://login.microsoftonline.com/common/oauth2/nativeclient` |

> ⚠️ **重定向 URI 必须一字不差**，多一个斜杠、少一个字母都登不上。
> 选「移动和桌面应用程序」这个平台时，这个地址通常就在候选列表里，勾上即可。

> 🚫 **命名禁区（硬性要求，踩了就白填）**
> 应用名字里**不许出现**这几个词：`Mojang`、`Minecraft`、`Microsoft`、`Live`、
> `Xbox`、`Discord`、`Hypixel`。
> 所以**别叫「Minecraft启动器」「MC启动器」**这类名字——用 `Maoqiu Launcher`
> 或 `毛球启动器` 这种。**这一条只管"应用名字"那一栏**，表格里别处让你说明用途时正常写就行。

点「**注册**」。

### 3. 抄下两个编号（都要用）

注册完会自动跳到应用页面。页面上有**两串东西**，都抄下来：

| 页面上叫什么 | 长什么样 | 有什么用 |
|---|---|---|
| 「**应用程序(客户端) ID**」<br>Application (client) ID | `12345678-1234-1234-1234-123456789abc` | **填进毛球**，递表时也要 |
| 「**目录(租户) ID**」<br>Directory (tenant) ID | 也是一串同样格式的 | **递表时必须给**，毛球用不到 |

> 两串长得一模一样，别抄混了。页面上的字是「客户端」的那个给毛球，是「租户」的那个留给递表。
> （页面上有复制按钮，点一下就行。）

### 4. ⚠️ 一定要打开的那个开关（不打开就登不上）

**左边菜单先点「管理」把它展开**（默认是折叠的，右边有个 `>`），
然后找「**Authentication (Preview)**」——**注意：这一项现在没翻译成中文**，
搜"身份验证"是搜不到的（2026-10-08 用户实际卡在这儿）。

进去之后，那一页是**分标签**的：

```
重定向 URI 配置  |  Supported accounts  |  设置      ← 点「设置」
```

在「**设置**」标签里找「**允许公共客户端流**」（Allow public client flows）→
打开 → **点左下角的「保存」**。

> **为什么必须打开**：毛球是桌面程序，没法安全地保存"应用密钥"（那个东西一旦写在软件里
> 等于公开）。所以走的是"公共客户端"这条路——微软要求这种情况下**必须**把它打开。

> **实在找不到的备用办法**：左边「**清单**」（Manifest）→ 把 `"allowPublicClient"`
> 改成 `true` → 保存。效果一模一样，只是不给开关、直接改值。

### 5. 完事

到这儿客户端 ID 就能用了，**不需要密钥**（别去生成密钥，用不上）。

把 ID 填进毛球：**设置页 → 正版登录 → 客户端 ID**，然后到启动页左边点「正版」登录试试。

## 第二部分：申请 Mojang 的许可（决定能不能真的进游戏）

**这一步不做的话**，前面全走通了，**最后一步也会被挡**——
微软那边会回一句 `403 Invalid app registration`（意思是"这个应用没登记过"）。

> **说准一点**：这句"会被挡"指的是**你自己新注册的 ID**（还没进名单）。
> 已经进了 Mojang 名单的 ID 不会被挡——**官方启动器自己那个就是**。
> 但那是**别人的应用身份**，而且不归我们管（人家哪天限流或停掉，
> 你会毫无预兆地登不上还查不出原因），所以毛球**不内置、也不借用**它。

### 1. 打开申请表

**https://aka.ms/mce-reviewappid**

（这个网址会跳到一个微软表单，标题叫 **AppID Review**。）

### 2. 表里只有两栏，照抄

| 表格问什么 | 填什么 |
|---|---|
| **Application ID** | 第 3 步抄下来的「**应用程序(客户端) ID**」 |
| **Directory (Tenant) ID** | 第 3 步抄下来的「**目录(租户) ID**」 |

> ⚠️ **一次只提交一个应用**。两栏都是 GUID（`8-4-4-4-12` 那种格式），
> 填错一个字都会被打回。

### 3. 然后就是等

- **等待时间**：有人实测 **3~4 周**才收到邮件回复
- 批了会收到一封邮件（有人说是 **Mojang Enforcement** 发的），说这个应用进了名单

**必须说清楚的**：批不批、要多久，**都不归我们控制**。
有人在微软自己的问答区问过，得到的答复前后不一致（被踢到 ID@Xbox，那边又说"这事不归我管"）。
所以：**填了表就等着，别指望它**。等待期间毛球照常用（离线、外置登录都不受影响）。

### 4. 批了之后

把客户端 ID 填进毛球的「设置 → 账号」，**不用改任何代码**——
登录、进游戏、皮肤那三样都已经做好了。

---

## 实际打开表格之后（2026-10-08 实测，共 9 栏）

网上查到的资料只说两栏，**实际打开有 9 栏**。照着填：

| # | 那一栏 | 填什么 |
|---|---|---|
| 1 | EULA 那题 | **选 `Yes`** |
| 2 | Contact Information | Azure 里登录用的那个邮箱（他们要用它去 Azure 核对） |
| 3 | What type of request | `New AppID for Approval` |
| 4 | Application Name | `Maoqiu Launcher` |
| 5 | Application ID | 客户端 ID |
| 6 | Tenant ID | 目录(租户) ID |
| 7 | **Associated website or domain** | **要一个公开网址**——见下 |
| 8 | **Justification** | **最要紧的一栏**，见下 |
| 9 | Any other information | `Personal single-user use only. Not distributed to the public.` |

### 第 7 栏：得先有个"别人点得开"的网页

它要一个"能了解你这个软件"的网址。**审核的人在国外**，所以那个网址得满足：
① 国内能打开（你才做得出来）② **不用登录就能看**（他没有你的账号）③ 国外也打得开。

⚠️ **GitHub 在国内经常被重置（`ERR_CONNECTION_RESET`），实测打不开**。
**用 Gitee（码云 `gitee.com`）**——步骤和 GitHub 一样，国内稳，国外也能开。

- 建仓库时选「**开源（所有人可见）**」和「**初始化仓库**」（语言随便，**许可证留空**）
- ⚠️ Gitee 可能拦一下："帐号安全评级较低，发布公开内容前请完成 2FA 或绑定可靠第三方帐号"
  → **绑个 QQ 或微信就行**（一分钟）
- 仓库地址形如 `https://gitee.com/用户名/仓库名`

**必做的检查**：开一个**无痕窗口**贴进去，**不登录能看到内容**才作数。

### 第 8 栏：Justification（照抄）

```
I am the developer of Maoqiu Launcher, a personal, non-commercial desktop
launcher for Minecraft Java Edition that runs entirely on the user's own
computer. It signs in the user's own Microsoft account and launches the game
with that account's credentials.

A client ID is required so the launcher can complete the standard sign-in flow
(Xbox Live / XSTS) and obtain the user's own Minecraft profile, which the game
needs in order to authenticate when joining a server.

The application does not bypass any authentication, licensing or security
checks: the user must own Minecraft Java Edition and signs in exclusively on
Microsoft's own login page. It has no server-side component and is not
distributed publicly.
```

> 最后那两句是**特意写的**：表头写着"绕过安全检查的应用一律不批"，
> 得先把这条堵上。**也别写成商用、别写要给别人用**——那会走到另一套审批流程去。

### 表头还有两句值得知道

- **"Submissions are reviewed weekly"** —— 按周审，所以可能比"3~4 周"快
- 命名禁区那条，表头又写了一遍（Mojang / Minecraft / Microsoft / Live / Xbox /
  Discord / Hypixel）

## 现在到底能做到哪一步（别抱错期望）

| 阶段 | 你能看到什么 |
|---|---|
| 注册完 + 填了 ID | 点「正版登录」→ 微软登录窗口弹出来 → 你登进去 → **一路走到最后** → Mojang 回一句"这个应用没登记"（我会翻成中文告诉你） |
| Mojang 批了 | **同一份代码，什么都不用改** → 直接变成"已登录：你的角色名"，然后就能进正版服务器了 |

---

## 遇到问题怎么办

| 现象 | 多半是 |
|---|---|
| 登录窗口里微软说"应用未获授权"/`AADSTS` 开头的错 | 客户端 ID 填错了，或者第 4 步那个勾没打 |
| 登录窗口里微软说"重定向 URI 不匹配" | 第 2 步那个地址和代码里用的**不完全一样** |
| 报 `The request is not valid for the application's 'userAudience' configuration` | **应用的"账户类型"和登录入口对不上**（2026-10-08 实际踩到）。毛球现在会自动换另一个入口重试，所以**新版不用管**；但如果还报，就去 Azure → 你的应用 → **清单**，把 `"signInAudience"` 改成 `"AzureADandPersonalMicrosoftAccount"`，保存，再试 |
| 走到最后一步 Mojang 挡回来 | **正常**，就是第二部分那个审批还没下来 |
| 说"这个微软账号没有 Xbox 账号" | 需要先去 xbox.com 用同一个账号建一个 Xbox 档案 |
| 说"这个账号没买 Java 版" | 这个微软账号名下确实没有正版 Java 版 |
